<p className="book-subtitle">Chapter 12 · Building Lossless Trees with Rowan</p>

Our arithmetic parser can build expression trees, but those trees leave
source details behind. We'll introduce Rowan to store lossless syntax.
Before its nodes can share locations with our scanner and errors, the
pieces need to agree on what a text offset is.

Our `TextSize` currently wraps `usize`. Rowan uses a 32-bit byte measure.
Both count UTF-8 bytes; they differ in capacity and in their Rust APIs.
A source length that fits `usize` might not fit the tree's coordinates:

```text title="Check the count before narrowing it"
source.len(): usize
       │ checked conversion
       ├─ 0 through 4,294,967,295 bytes → TextSize
       └─ larger byte count           → SourceTooLarge, without a range
```

The letter `é` still occupies two bytes. No offsets turn into character
indices, UTF-16 units or display columns. This is a representation migration
with an explicit input boundary, not a change to the arithmetic grammar.

Start from [Section 11.5](/chapter-11/11.5-parse-terms/), in the **Rust
workspace directory**. The following edits form one cross-crate migration:
**finish the text, scanner, parser, example and app changes before checking
compilation**. Complete resulting files are available at the end; required
test patches are shown with their corresponding caller changes.

## Give coordinates one owner

Add this dependency section to **`rlox/crates/text/Cargo.toml`**:

```toml title="rlox/crates/text/Cargo.toml · append dependencies"
[dependencies]
rowan = "=0.17.0"
```

We pin the direct dependency and let Cargo record its resolved dependencies
in the workspace lockfile. Rowan [re-exports the coordinate types](https://docs.rs/rowan/0.17.0/rowan/).
Its underlying [TextSize contract](https://docs.rs/text-size/latest/text_size/struct.TextSize.html)
provides checked conversion from `usize` and conversion back for string
indexing. We won't build syntax nodes in this section.

Replace the two custom coordinate structs and their implementations at the
start of **`rlox/crates/text/src/lib.rs`**, keeping the file identity types,
with the complete production portion below. The tests will be adjusted
next.

```rust title="rlox/crates/text/src/lib.rs · production definitions before tests"
use std::fmt;

pub use rowan::{TextRange, TextSize};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct SourceTooLarge;

impl fmt::Display for SourceTooLarge {
    fn fmt(&self, formatter: &mut fmt::Formatter<'_>) -> fmt::Result {
        formatter.write_str("source exceeds the 4,294,967,295-byte size limit")
    }
}

pub fn checked_size(bytes: usize) -> Result<TextSize, SourceTooLarge> {
    TextSize::try_from(bytes).map_err(|_| SourceTooLarge)
}

pub fn checked_range(start: TextSize, end: TextSize) -> Option<TextRange> {
    if start > end {
        return None;
    }
    Some(TextRange::new(start, end))
}

pub fn slice(source: &str, range: TextRange) -> Option<&str> {
    source.get(usize::from(range.start())..usize::from(range.end()))
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct FileId(pub usize);

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct SyntaxOrigin {
    pub file: FileId,
    pub range: TextRange,
}
```

`pub use` [re-exports](https://doc.rust-lang.org/book/ch07-04-bringing-paths-into-scope-with-the-use-keyword.html#re-exporting-names-with-pub-use) Rowan's actual types through our existing text package.
We aren't creating another wrapper that callers must translate into tree
coordinates later. The standard `TryFrom` conversion in `checked_size`
rejects a byte count that can't fit; `map_err` gives that failure a name in
our API.

`SourceTooLarge` is file-level information. There is no representable range
covering the oversized source, so the error doesn't invent one. Its
`Display` implementation supplies the message used by `{error}` in a
terminal or example. The formatter writes that text; it doesn't print on
its own. See the standard library's
[Display contract](https://doc.rust-lang.org/std/fmt/trait.Display.html).

There are two other API differences. Rowan's
[`TextRange::new`](https://docs.rs/text-size/latest/text_size/struct.TextRange.html#method.new)
returns a range directly and panics if the endpoints are reversed. Our
`checked_range` keeps the previous checked-construction behavior, returning
`None` for that case. And Rowan owns these types, so our safe slicing
convenience becomes the free function `slice(source, range)` rather than
an inherent `.slice` method. It converts offsets to `usize` and uses
`str::get`, preserving rejection of out-of-bounds or non-boundary UTF-8
ranges.

Known small constants can use `TextSize::new(5)`, whose argument is `u32`.
Measured `usize` values use `checked_size(...)`. A range's byte endpoints
convert back with `usize::from(range.start())`, instead of accessing a
public `.0` field. `FileId` remains an identity index; its representation
hasn't changed.

## Reject an oversized source before lexing

In **`rlox/crates/syntax/src/lib.rs`**, replace the text import:

```diff title="rlox/crates/syntax/src/lib.rs · coordinate and input-error imports"
-use rlox_text::{TextRange, TextSize};
+use rlox_text::{SourceTooLarge, TextRange, checked_range, checked_size};
```

Replace the existing public `scan` function with:

```rust title="rlox/crates/syntax/src/lib.rs · checked scanner entry point"
pub fn scan(source: &str) -> Result<Vec<Token>, SourceTooLarge> {
    checked_size(source.len())?;
    let mut tokens = Vec::new();

    for (result, span) in SyntaxKind::lexer(source).spanned() {
        let kind = match result {
            Ok(kind) => kind,
            Err(()) => SyntaxKind::Error,
        };
        let range = checked_range(
            checked_size(span.start).expect("validated source length"),
            checked_size(span.end).expect("validated source length"),
        )
        .expect("Logos spans are ordered");

        tokens.push(Token { kind, range });
    }

    Ok(tokens)
}
```

`scan` now returns `Result<Vec<Token>, SourceTooLarge>`. Its first operation
checks the full byte length. Once that succeeds, each lexer span is within
the validated source, so the later conversions enforce an internal
invariant. No narrowing cast silently truncates an offset.

A lexical error is still an ordinary `Error` token in `Ok(tokens)`. This
new `Err` means the source can't be represented at all. Keeping those two
cases separate preserves the token inspector's complete listing of
representable malformed source.

In the existing scanner tests, every input is small, so each `scan(...)`
call now checks `expect("small test source")` before inspecting its vector.
The token expectations stay the same; their constructors, slices and
endpoint conversions use the new text API. Apply the full required patch:

## Separate input failure from a syntax error

Our existing `ParseError` still describes a located syntax problem. Keep
that struct and its fields. A source-capacity failure needs a different
case at the public entry point, before grammar rules run.

In **`rlox/crates/syntax/src/parser.rs`**, change the text import:

```diff title="rlox/crates/syntax/src/parser.rs · text helpers"
-use rlox_text::{TextRange, TextSize};
+use rlox_text::{SourceTooLarge, TextRange, checked_range, checked_size, slice};
```

Insert this enum **after `ParseError` and before `error_at`**:

```rust title="rlox/crates/syntax/src/parser.rs · public failure categories"
#[derive(Debug)]
pub enum ParseFailure {
    SourceTooLarge(SourceTooLarge),
    Syntax(ParseError),
}
```

Grammar methods keep returning `Result<Expr, ParseError>`. Replace only the
public `parse` function with this boundary adapter:

```rust title="rlox/crates/syntax/src/parser.rs · replace public parse"
pub fn parse(source: &str) -> Result<Expr, ParseFailure> {
    let mut parser = Parser::new(source).map_err(ParseFailure::SourceTooLarge)?;
    let expr = parser.expression(0).map_err(ParseFailure::Syntax)?;
    if parser.peek().is_some() {
        return Err(ParseFailure::Syntax(parser.error("expected end of input")));
    }
    Ok(expr)
}
```

The two `map_err` calls label the stage that failed. An enum variant's
constructor can serve as the conversion function. An input failure carries
no syntax range; a syntax failure carries the existing message and range.
The full-input check still rejects leftover tokens.

Change the private `Parser::new` method to return the scanner's failure
instead of assuming a token vector:

```rust title="rlox/crates/syntax/src/parser.rs · replace constructor"
    fn new(source: &'src str) -> Result<Self, SourceTooLarge> {

        tokens.retain(|token| {
            !matches!(token.kind, SyntaxKind::Whitespace | SyntaxKind::LineComment)

        Ok(Self {
            source,

    }
```

edits remain in the production methods. In `number`, replace its spelling
lookup with:

```rust title="rlox/crates/syntax/src/parser.rs · number spelling lookup"

```


```rust title="rlox/crates/text/src/lib.rs · complete resulting file"
use std::fmt;

pub use rowan::{TextRange, TextSize};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct SourceTooLarge;

impl fmt::Display for SourceTooLarge {
    fn fmt(&self, formatter: &mut fmt::Formatter<'_>) -> fmt::Result {
        formatter.write_str("source exceeds the 4,294,967,295-byte size limit")
    }
}

pub fn checked_size(bytes: usize) -> Result<TextSize, SourceTooLarge> {
    TextSize::try_from(bytes).map_err(|_| SourceTooLarge)
}

pub fn checked_range(start: TextSize, end: TextSize) -> Option<TextRange> {
    if start > end {
        return None;
    }
    Some(TextRange::new(start, end))
}

pub fn slice(source: &str, range: TextRange) -> Option<&str> {
    source.get(usize::from(range.start())..usize::from(range.end()))
```
```rust title="rlox/crates/syntax/src/parser.rs · complete resulting file"
}

fn error_at(token: Token, message: &str) -> ParseError {
    let message = if token.kind == SyntaxKind::Error {
        "invalid token"
    } else {
        message

    ParseError {
        message: message.to_owned(),

fn tree_height(expr: &Expr) -> usize {
    match expr {
        Expr::Number(_) => 0,
        Expr::Grouping(child) => 1 + tree_height(child),
        Expr::Unary { right, .. } => 1 + tree_height(right),
        Expr::Binary { left, right, .. } => 1 + tree_height(left).max(tree_height(right)),
    }
}

pub fn parse(source: &str) -> Result<Expr, ParseFailure> {
    let mut parser = Parser::new(source).map_err(ParseFailure::SourceTooLarge)?;
    let expr = parser.expression(0).map_err(ParseFailure::Syntax)?;
    if parser.peek().is_some() {
        return Err(ParseFailure::Syntax(parser.error("expected end of input")));
    }
    Ok(expr)
}

struct Parser<'src> {
    source: &'src str,
    tokens: Vec<Token>,
    current: usize,
}

impl<'src> Parser<'src> {
    fn new(source: &'src str) -> Result<Self, SourceTooLarge> {
        let mut tokens = scan(source)?;
        tokens.retain(|token| {
            !matches!(token.kind, SyntaxKind::Whitespace | SyntaxKind::LineComment)
        });
        Ok(Self {
            source,
            tokens,
            current: 0,
        })
    }

    fn expression(&mut self, nesting: usize) -> Result<Expr, ParseError> {
        self.term(nesting)
    }

    fn term(&mut self, nesting: usize) -> Result<Expr, ParseError> {
        let mut expr = self.factor(nesting)?;
        let mut height = tree_height(&expr);

        while let Some(token) = self.peek() {
            let op = match token.kind {
                SyntaxKind::Plus => BinaryOp::Add,
                SyntaxKind::Minus => BinaryOp::Subtract,
                _ => break,
            };
            self.bump();
            let right = self.factor(nesting)?;
            let next_height = 1 + height.max(tree_height(&right));
            if nesting + next_height > MAX_NESTING {
                return Err(error_at(token, "expression nesting limit exceeded"));
            }
            expr = Expr::Binary {
                left: Box::new(expr),
                op,
                right: Box::new(right),
            };
            height = next_height;
        }

        Ok(expr)
    }

    fn factor(&mut self, nesting: usize) -> Result<Expr, ParseError> {
        let mut expr = self.unary(nesting)?;
        let mut height = tree_height(&expr);

        while let Some(token) = self.peek() {
            let op = match token.kind {
                SyntaxKind::Star => BinaryOp::Multiply,
                SyntaxKind::Slash => BinaryOp::Divide,
                _ => break,
            };
            self.bump();
            let right = self.unary(nesting)?;
            let next_height = 1 + height.max(tree_height(&right));
            if nesting + next_height > MAX_NESTING {
                return Err(error_at(token, "expression nesting limit exceeded"));
            }
            expr = Expr::Binary {
                left: Box::new(expr),
                op,
                right: Box::new(right),
            };
            height = next_height;
        }

        Ok(expr)
    }

    fn unary(&mut self, nesting: usize) -> Result<Expr, ParseError> {
        match self.peek() {
            Some(token) if token.kind == SyntaxKind::Minus => {
                if nesting >= MAX_NESTING {
                    return Err(self.error("expression nesting limit exceeded"));
                }
                self.bump();
                let right = self.unary(nesting + 1)?;
                Ok(Expr::Unary {
                    op: UnaryOp::Negate,
                    right: Box::new(right),
                })
            }
            _ => self.primary(nesting),
        }
    }

    fn primary(&mut self, nesting: usize) -> Result<Expr, ParseError> {
        let token = match self.peek() {
            Some(token) => token,
            None => return Err(self.error("expected an expression")),
        };
        match token.kind {
            SyntaxKind::Number => self.number(),
            SyntaxKind::LeftParen => {
                if nesting >= MAX_NESTING {
                    return Err(self.error("expression nesting limit exceeded"));
                }
                self.bump();
                let inner = self.expression(nesting + 1)?;
                match self.peek() {
                    Some(close) if close.kind == SyntaxKind::RightParen => self.bump(),
                    _ => return Err(self.error("expected ')'")),
                }
                Ok(Expr::Grouping(Box::new(inner)))
            }
            _ => Err(self.error("expected an expression")),
        }
    }

    fn number(&mut self) -> Result<Expr, ParseError> {
        let token = match self.peek() {
            Some(token) => token,
            None => return Err(self.error("expected a number")),
        };
        if token.kind != SyntaxKind::Number {
            return Err(self.error("expected a number"));
        }

        let spelling = slice(self.source, token.range).expect("scanner ranges are valid");
        let value = spelling
            .parse::<f64>()
            .map_err(|_| error_at(token, "invalid number"))?;
        self.bump();
        Ok(Expr::Number(value))
    }

    fn peek(&self) -> Option<Token> {
        self.tokens.get(self.current).copied()
    }

    fn bump(&mut self) {
        self.current += 1;
    }

    fn error(&self, message: &str) -> ParseError {
        match self.peek() {
            Some(token) => error_at(token, message),
            None => {
                let end = checked_size(self.source.len()).expect("validated source length");
                ParseError {
                    message: message.to_owned(),
                    range: checked_range(end, end).expect("ordered EOF range"),
                }
            }
        }
    }
```

```rust title="rlox/crates/app/src/main.rs · complete resulting file"
use std::process::ExitCode;

use clap::{Parser, Subcommand};
use rlox_syntax::{SyntaxKind, scan};
use rlox_text::slice;

#[derive(Parser)]
#[command(name = "rlox", about = "Inspect Lox source files")]
struct Cli {
    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand)]
enum Command {
    /// Display a file's source text.
    Source {
        /// File whose text should be displayed.
        file: String,
    },
    /// Display a file's tokens and source ranges.
    Tokens {
        /// File whose tokens should be displayed.
        file: String,
    },
}

fn main() -> ExitCode {
    let command = Cli::parse().command;
    let filename = match &command {
        Command::Source { file } | Command::Tokens { file } => file,
    };
    let source = match std::fs::read_to_string(filename) {
        Ok(source) => source,
        Err(error) => {
            eprintln!("rlox: could not read '{filename}': {error}");
            return ExitCode::FAILURE;
        }
    };
    match command {
        Command::Source { .. } => print!("{source}"),
        Command::Tokens { .. } => {
            let tokens = match scan(&source) {
                Ok(tokens) => tokens,
                Err(error) => {
                    eprintln!("rlox: {error}");
                    return ExitCode::FAILURE;
                }
            };
            let mut had_error = false;
            for token in tokens {
                if token.kind == SyntaxKind::Error {
                    had_error = true;
                }
                let spelling = slice(&source, token.range).expect("scanner ranges are valid");
                println!(
                    "{:?} [{}..{}) {:?}",
                    token.kind,
                    usize::from(token.range.start()),
                    usize::from(token.range.end()),
                    spelling
                );
            }
            if had_error {
                eprintln!("rlox: scan contains lexical errors");
                return ExitCode::FAILURE;
            }
        }
    }
    ExitCode::SUCCESS
}
```
