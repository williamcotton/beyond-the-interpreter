<p className="book-subtitle">Chapter 12 · Building Lossless Trees with Rowan</p>

Our concrete tree keeps the syntax we need, including incomplete
expressions. Reading it still requires a kind check and child traversal
every time we want a number token or the right operand of a binary node.
Let's give those operations names that describe the node we are reading.

The distinction matters for `* 2`. The raw binary node has two expression
slots: a zero-width `MissingExpr`, followed by `NumberExpr`. A right-operand
accessor should return the number; a left-operand accessor should return
`None`. Trying a binary accessor on a number node is a different mistake:
it isn't a binary node in the first place.

```text title="Check the receiver kind, then read a field"
NumberExpr node ── BinaryExpr::cast ── None (wrong receiver kind)

BinaryExpr node for * 2 ── BinaryExpr::cast ── Some(binary view)
                                              left()  → None
                                              right() → Some(number view)
```

We'll use small **typed views** around Rowan node handles. Each specific
type offers only its own fields. Casting checks the receiver's kind once;
accessors can then focus on children and tokens. The view reads the
existing tree without copying it into another owned AST.

The [expression types in Crafting Interpreters](https://craftinginterpreters.com/representing-code.html#implementing-syntax-trees)
provide useful names for literals, grouping and operators. Here those names
select views of retained source structure.

Start from [12.6](/chapter-12/12.6-incomplete-syntax/), in the **Rust workspace
directory**. We'll keep the owned parser available until the new views,
inspection example and parity checks are working, then remove that
transitional implementation from the active build.

Create **`rlox/crates/syntax/src/ast.rs`** with:

```rust title="rlox/crates/syntax/src/ast.rs · view types"
use crate::SyntaxKind;
use crate::tree::{SyntaxNode, SyntaxToken};

#[derive(Debug, Clone)]
pub struct NumberExpr {
    syntax: SyntaxNode,
}
#[derive(Debug, Clone)]
pub struct GroupingExpr {
    syntax: SyntaxNode,
}
#[derive(Debug, Clone)]
pub struct UnaryExpr {
    syntax: SyntaxNode,
}
#[derive(Debug, Clone)]
pub struct BinaryExpr {
    syntax: SyntaxNode,
}

#[derive(Debug, Clone)]
pub enum Expr {
    Number(NumberExpr),
    Grouping(GroupingExpr),
    Unary(UnaryExpr),
    Binary(BinaryExpr),
}
```

Each struct stores one `SyntaxNode` handle. Its field is private, so callers
must enter through a checked constructor. The `Expr` enum groups the four
possible views without giving all of them a `left` or `operator` method.
The Rust Book's [enum discussion](https://doc.rust-lang.org/book/ch06-01-defining-an-enum.html#enum-values)
explains this use of variants with different associated data.

Unlike our earlier `Expr`, this enum has no recursive child fields and no
`Box<Expr>`. Getters will create more views from Rowan's children when
requested. Cloning a view clones its node handle; it doesn't rebuild the
green tree or discard source text.

Append this implementation to **`ast.rs`**:

```rust title="rlox/crates/syntax/src/ast.rs · expression cast and source handle"
impl Expr {
    pub fn cast(syntax: SyntaxNode) -> Option<Self> {
        match syntax.kind() {
            SyntaxKind::NumberExpr => Some(Self::Number(NumberExpr { syntax })),
            SyntaxKind::GroupingExpr => Some(Self::Grouping(GroupingExpr { syntax })),
            SyntaxKind::UnaryExpr => Some(Self::Unary(UnaryExpr { syntax })),
            SyntaxKind::BinaryExpr => Some(Self::Binary(BinaryExpr { syntax })),
            _ => None,
        }
    }

    pub fn syntax(&self) -> &SyntaxNode {
        match self {
            Self::Number(node) => node.syntax(),
            Self::Grouping(node) => node.syntax(),
            Self::Unary(node) => node.syntax(),
            Self::Binary(node) => node.syntax(),
        }
    }
}
```

`Expr::cast` accepts expression node kinds and rejects everything else,
including `Root` and `MissingExpr`. A missing slot therefore isn't a fake
number or a new executable expression variant. `syntax()` exposes the
underlying handle for source text, ranges and parent relationships.

## Read number tokens without losing spelling

Append:

```rust title="rlox/crates/syntax/src/ast.rs · number view"
impl NumberExpr {
    pub fn cast(syntax: SyntaxNode) -> Option<Self> {
        if syntax.kind() != SyntaxKind::NumberExpr {
            return None;
        }
        Some(Self { syntax })
    }

    pub fn syntax(&self) -> &SyntaxNode {
        &self.syntax
    }

    pub fn token(&self) -> Option<SyntaxToken> {
        self.syntax
            .children_with_tokens()
            .filter_map(|element| element.into_token())
            .find(|token| token.kind() == SyntaxKind::Number)
    }
}
```

A specific cast accepts only that specific receiver kind. Once it succeeds,
`token` searches the node's direct token children for `Number`. It returns
a `SyntaxToken`, preserving spelling and byte range. For `001.50`, its text
is still `001.50`.

`children_with_tokens` includes both nodes and tokens. Here `filter_map`
keeps token children and then `find` chooses the requested token kind.
These are Rowan's [positioned node operations](https://docs.rs/rowan/0.17.0/rowan/api/struct.SyntaxNode.html#method.children_with_tokens).
We use an `Option` because an accessor can encounter incomplete structure;
a checked receiver kind alone isn't a guarantee that every field exists.

## Read groups and unary expressions

Append the grouping implementation:

```rust title="rlox/crates/syntax/src/ast.rs · grouping view"
impl GroupingExpr {
    pub fn cast(syntax: SyntaxNode) -> Option<Self> {
        if syntax.kind() != SyntaxKind::GroupingExpr {
            return None;
        }
        Some(Self { syntax })
    }

    pub fn syntax(&self) -> &SyntaxNode {
        &self.syntax
    }

    pub fn inner(&self) -> Option<Expr> {
        self.syntax.first_child().and_then(Expr::cast)
    }

    pub fn l_paren_token(&self) -> Option<SyntaxToken> {
        self.syntax
            .children_with_tokens()
            .filter_map(|element| element.into_token())
            .find(|token| token.kind() == SyntaxKind::LeftParen)
    }

    pub fn r_paren_token(&self) -> Option<SyntaxToken> {
        self.syntax
            .children_with_tokens()
            .filter_map(|element| element.into_token())
            .find(|token| token.kind() == SyntaxKind::RightParen)
    }
}
```

`inner` reads the first node slot and tries to cast it as an expression.
If it is a `MissingExpr`, the result is `None`. Delimiter getters return
only actual source tokens. For `(1`, the inner number is present while
`r_paren_token()` is `None`; recovery hasn't fabricated a close.

Append the unary implementation:

```rust title="rlox/crates/syntax/src/ast.rs · unary view"
impl UnaryExpr {
    pub fn cast(syntax: SyntaxNode) -> Option<Self> {
        if syntax.kind() != SyntaxKind::UnaryExpr {
            return None;
        }
        Some(Self { syntax })
    }

    pub fn syntax(&self) -> &SyntaxNode {
        &self.syntax
    }

    pub fn operator_token(&self) -> Option<SyntaxToken> {
        self.syntax
            .children_with_tokens()
            .filter_map(|element| element.into_token())
            .find(|token| token.kind() == SyntaxKind::Minus)
    }

    pub fn operand(&self) -> Option<Expr> {
        self.syntax.first_child().and_then(Expr::cast)
    }
}
```

A unary view has an operator token and an operand. For a lone `-`, the
operator is present, but casting the missing operand slot returns `None`.
There is no `operand` method on `NumberExpr` for callers to apply to the
wrong receiver.

## Choose a binary slot before casting it

Append:

```rust title="rlox/crates/syntax/src/ast.rs · binary view"
impl BinaryExpr {
    pub fn cast(syntax: SyntaxNode) -> Option<Self> {
        if syntax.kind() != SyntaxKind::BinaryExpr {
            return None;
        }
        Some(Self { syntax })
    }

    pub fn syntax(&self) -> &SyntaxNode {
        &self.syntax
    }

    pub fn left(&self) -> Option<Expr> {
        self.syntax.first_child().and_then(Expr::cast)
    }

    pub fn right(&self) -> Option<Expr> {
        self.syntax.children().nth(1).and_then(Expr::cast)
    }

    pub fn operator_token(&self) -> Option<SyntaxToken> {
        self.syntax
            .children_with_tokens()
            .filter_map(|element| element.into_token())
            .find(|token| {
                matches!(
                    token.kind(),
                    SyntaxKind::Plus | SyntaxKind::Minus | SyntaxKind::Star | SyntaxKind::Slash
                )
            })
    }
}
```

The order is deliberate: select the first or second **node slot**, then
cast that node. `children` skips tokens, including trivia and unexpected
tokens retained by recovery. It still includes `MissingExpr` nodes.

For `* 2`, the first slot casts to `None`, and the second casts to a number
view. Filtering out missing nodes *before* selecting a position would
shift that number into the left slot. `1 +` has the opposite absence:
its left view exists and its right view is `None`.

The operator search inspects direct token children only. A star inside a
right-hand binary child isn't mistaken for the sum's plus. This keeps
node structure and source-token access connected.

## Project a complete view for inspection

Our existing observer prints prefix notation. We can keep that useful
observation without keeping the owned model. Add this method **inside
`impl Expr`, after `syntax` and before the implementation's closing brace**:

```rust title="rlox/crates/syntax/src/ast.rs · optional prefix projection"
    pub fn to_prefix(&self) -> Option<String> {
        match self {
            Self::Number(node) => {
                let token = node.token()?;
                let value = token.text().parse::<f64>().ok()?;
                Some(value.to_string())
            }
            Self::Grouping(node) => {
                node.l_paren_token()?;
                node.r_paren_token()?;
                Some(format!("(group {})", node.inner()?.to_prefix()?))
            }
            Self::Unary(node) => Some(format!(
                "({} {})",
                node.operator_token()?.text(),
                node.operand()?.to_prefix()?
            )),
            Self::Binary(node) => Some(format!(
                "({} {} {})",
                node.operator_token()?.text(),
                node.left()?.to_prefix()?,
                node.right()?.to_prefix()?
            )),
        }
    }
```

Each `?` here operates on `Option`: if a required token or child is absent,
the projection returns `None`. Grouping also requires both source
delimiters. The Rust Book explains the same [optional-value contract](https://doc.rust-lang.org/book/ch06-01-defining-an-enum.html#the-option-enum).

Number formatting parses the token's text as `f64`, just as our earlier
inspector did, so `001.50` displays as `1.5` in prefix notation. This is an
inspection projection, not evaluation or a lowered runtime representation.
The node and token still preserve the original spelling.

A `Some` prefix isn't a syntax-validity check: recovery can retain an
unexpected token alongside otherwise readable fields. Callers must still
inspect `Parse.errors`. Typed views describe available structure; they
don't erase diagnostics.

impl Expr {
    pub fn cast(syntax: SyntaxNode) -> Option<Self> {
        match syntax.kind() {
            SyntaxKind::NumberExpr => Some(Self::Number(NumberExpr { syntax })),
            SyntaxKind::GroupingExpr => Some(Self::Grouping(GroupingExpr { syntax })),
            SyntaxKind::UnaryExpr => Some(Self::Unary(UnaryExpr { syntax })),
            SyntaxKind::BinaryExpr => Some(Self::Binary(BinaryExpr { syntax })),
            _ => None,
        }
    }

    pub fn syntax(&self) -> &SyntaxNode {
        match self {
            Self::Number(node) => node.syntax(),
            Self::Grouping(node) => node.syntax(),
            Self::Unary(node) => node.syntax(),
            Self::Binary(node) => node.syntax(),
        }
    }

    pub fn to_prefix(&self) -> Option<String> {
        match self {
            Self::Number(node) => {
                let token = node.token()?;
                let value = token.text().parse::<f64>().ok()?;
                Some(value.to_string())
            }
            Self::Grouping(node) => {
                node.l_paren_token()?;
                node.r_paren_token()?;
                Some(format!("(group {})", node.inner()?.to_prefix()?))
            }
            Self::Unary(node) => Some(format!(
                "({} {})",
                node.operator_token()?.text(),
                node.operand()?.to_prefix()?
            )),
            Self::Binary(node) => Some(format!(

                node.operator_token()?.text(),

pub fn scan(source: &str) -> Result<Vec<Token>, SourceTooLarge> {
    checked_size(source.len())?;
    let mut tokens = Vec::new();

    for (result, span) in SyntaxKind::lexer(source).spanned() {
        let kind = match result {
            Ok(kind) => kind,
            Err(()) => SyntaxKind::Error,
        };
        let range = checked_range(
            checked_size(span.start).expect("validated source length"),
            checked_size(span.end).expect("validated source length"),
        )
        .expect("Logos spans are ordered");

        tokens.push(Token { kind, range });
    }

    Ok(tokens)
}

pub struct ParseError {

    pub range: TextRange,

pub fn parse(source: &str) -> Result<Parse, SourceTooLarge> {
    let mut parser = Parser::new(source)?;
    parser.builder.start_node(SyntaxKind::Root.into_raw());
    if let Err(error) = parser.expression(0) {
        parser.errors.push(error);
        while parser.current < parser.tokens.len() {
            parser.bump();
        }
    } else {
        parser.eat_trivia();
        while parser.peek().is_some() {
            let error = parser.error("expected end of input");
            parser.errors.push(error);
            parser.bump();
            parser.eat_trivia();
        }
    }
    parser.builder.finish_node();
    let root = SyntaxNode::new_root(parser.builder.finish());
    Ok(Parse {
        root,
        errors: parser.errors,
    })
}

struct Parser<'src> {
    source: &'src str,
    tokens: Vec<Token>,
    current: usize,
    errors: Vec<ParseError>,
    builder: GreenNodeBuilder<'static>,
}

impl<'src> Parser<'src> {
    fn new(source: &'src str) -> Result<Self, SourceTooLarge> {
        Ok(Self {
            source,
            tokens: scan(source)?,
            current: 0,
            errors: Vec::new(),
            builder: GreenNodeBuilder::new(),
        })
    }

    fn peek(&self) -> Option<Token> {
        self.tokens.get(self.current).copied()
    }

    fn peek_non_trivia(&self) -> Option<Token> {
        self.tokens[self.current..]
            .iter()
            .copied()
            .find(|token| !matches!(token.kind, SyntaxKind::Whitespace | SyntaxKind::LineComment))
    }

    fn bump(&mut self) {
        let token = self.tokens[self.current];
        let spelling = slice(self.source, token.range).expect("scanner ranges are valid");
        self.builder.token(token.kind.into_raw(), spelling);
        self.current += 1;
    }

    fn eat_trivia(&mut self) {
        while let Some(token) = self.peek() {
            if !matches!(token.kind, SyntaxKind::Whitespace | SyntaxKind::LineComment) {
                break;
            }
            self.bump();
        }
    }

    fn error(&self, message: &str) -> ParseError {
        match self.peek() {
            Some(token) => ParseError {
                message: if token.kind == SyntaxKind::Error {
                    "invalid token".to_owned()
                } else {
                    message.to_owned()
                },
                range: token.range,
            },
            None => {
                let end = checked_size(self.source.len()).expect("validated source length");
                ParseError {
                    message: message.to_owned(),
                    range: checked_range(end, end).expect("ordered EOF range"),
                }
            }
        }
    }

    fn expression(&mut self, nesting: usize) -> Result<usize, ParseError> {
        self.term(nesting)
    }

    fn term(&mut self, nesting: usize) -> Result<usize, ParseError> {
        self.eat_trivia();
        let checkpoint = self.builder.checkpoint();
        let mut height = self.factor(nesting)?;

        while let Some(operator) = self.peek_non_trivia() {
            if !matches!(operator.kind, SyntaxKind::Plus | SyntaxKind::Minus) {
                break;
            }
            self.eat_trivia();
            self.bump();
            let right_height = self.factor(nesting)?;
            let next_height = 1 + height.max(right_height);
            if nesting + next_height > MAX_NESTING {
                return Err(ParseError {
                    message: "expression nesting limit exceeded".to_owned(),
                    range: operator.range,
                });
            }
            self.builder
                .start_node_at(checkpoint, SyntaxKind::BinaryExpr.into_raw());
            self.builder.finish_node();
            height = next_height;
        }

        Ok(height)
    }

    fn factor(&mut self, nesting: usize) -> Result<usize, ParseError> {
        self.eat_trivia();
        let checkpoint = self.builder.checkpoint();
        let mut height = self.unary(nesting)?;

        while let Some(operator) = self.peek_non_trivia() {
            if !matches!(operator.kind, SyntaxKind::Star | SyntaxKind::Slash) {
                break;
            }
            self.eat_trivia();
            self.bump();
            let right_height = self.unary(nesting)?;
            let next_height = 1 + height.max(right_height);
            if nesting + next_height > MAX_NESTING {
                return Err(ParseError {
                    message: "expression nesting limit exceeded".to_owned(),
                    range: operator.range,
                });
            }
            self.builder
                .start_node_at(checkpoint, SyntaxKind::BinaryExpr.into_raw());
            self.builder.finish_node();
            height = next_height;
        }

        Ok(height)
    }

    fn missing_expression(&mut self) {
        self.builder.start_node(SyntaxKind::MissingExpr.into_raw());
        self.builder.finish_node();
    }

    fn unary(&mut self, nesting: usize) -> Result<usize, ParseError> {
        let mut reported = false;
        loop {
            self.eat_trivia();
            match self.peek() {
                Some(token) if token.kind == SyntaxKind::Minus => {
                    if nesting >= MAX_NESTING {
                        return Err(self.error("expression nesting limit exceeded"));
                    }
                    self.builder.start_node(SyntaxKind::UnaryExpr.into_raw());
                    self.bump();
                    let result = self.unary(nesting + 1);
                    self.builder.finish_node();
                    return result.map(|height| height + 1);
                }
                Some(token) if matches!(token.kind, SyntaxKind::Number | SyntaxKind::LeftParen) => {
                    return self.primary(nesting);
                }
                None
                | Some(Token {
                    kind:
                        SyntaxKind::Plus | SyntaxKind::Star | SyntaxKind::Slash | SyntaxKind::RightParen,
                    ..
                }) => {
                    if !reported {
                        let error = self.error("expected an expression");
                        self.errors.push(error);
                    }
                    self.missing_expression();
                    return Ok(0);
                }
                Some(_) => {
                    let error = self.error("expected an expression");
                    self.errors.push(error);
                    self.bump();
                    reported = true;
                }
            }
        }
    }

    fn primary(&mut self, nesting: usize) -> Result<usize, ParseError> {
        match self.peek() {
            Some(token) if token.kind == SyntaxKind::Number => {
                self.builder.start_node(SyntaxKind::NumberExpr.into_raw());
                self.bump();
                self.builder.finish_node();
                Ok(0)
            }
            Some(token) if token.kind == SyntaxKind::LeftParen => self.group(nesting),
            _ => unreachable!("unary checks primary starters"),
        }
    }

    fn close_group(&mut self) {
        loop {
            self.eat_trivia();
            match self.peek() {
                Some(token) if token.kind == SyntaxKind::RightParen => {
                    self.bump();
                    break;
                }
                Some(_) => {
                    let error = self.error("expected ')'");
                    self.errors.push(error);
                    self.bump();
                }
                None => {
                    let error = self.error("expected ')'");
                    self.errors.push(error);
                    break;
                }
            }
        }
    }

    fn group(&mut self, nesting: usize) -> Result<usize, ParseError> {
        if nesting >= MAX_NESTING {
            return Err(self.error("expression nesting limit exceeded"));
        }
        self.builder.start_node(SyntaxKind::GroupingExpr.into_raw());
        self.bump();
        let result = match self.expression(nesting + 1) {
            Err(error) => Err(error),
            Ok(inner_height) => {
                self.close_group();
                Ok(inner_height + 1)
            }
        };
        self.builder.finish_node();
        result
    }
