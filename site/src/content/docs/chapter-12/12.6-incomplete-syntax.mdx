An editor often sees `1 +` while someone is still typing. Our parser keeps
those bytes, but it leaves the number and operator as siblings instead of
building a binary node. We'd like to inspect the intended operand positions
even before both operands exist.

A single surviving number isn't enough to name those positions. In `1 +`,
`1` is the left operand. In `* 2`, `2` is the right operand. Treating the
first child as the left operand in both cases would tell the wrong story.

We'll put a **zero-width `MissingExpr` node** in the absent slot. It has
no token and no text:

```text title="Keep the two operand roles, including the empty slot"
1 +                         * 2
BinaryExpr [0..3)            BinaryExpr [0..3)
  NumberExpr [0..1)            MissingExpr [0..0)
  Plus [2..3)                  Star [0..1)
  MissingExpr [3..3)            NumberExpr [2..3)
```

This outline omits the space tokens for clarity; the actual trees keep
them. Missing nodes express a structural absence. They don't insert a
number into the source or pretend that a missing `)` was typed.

Explore the incomplete examples. Select a missing node to see its exact
position; a vertical marker shows its empty range. The syntax errors below
the source describe what went wrong while the tree keeps all original text.

## Recover at an operand boundary

When an operand is missing, we must leave the operator or close delimiter
for the rule that owns it. The additive loop can consume `+`; the factor
loop can consume `*` or `/`; the group can consume `)`. At EOF there is
nothing to consume. These are the boundaries where we can emit a missing
slot and return.

Other unexpected tokens, such as an identifier or unsupported character,
can be reported and consumed while we keep looking for an operand. They
remain original token children of the current container. We aren't adding
another node wrapper around skipped text, so expression children retain
their operand roles.

Replace **`unary` in `cst.rs`** with:

```rust title="rlox/crates/syntax/src/cst.rs · recovering unary and operand dispatch"
    fn unary(&mut self, nesting: usize) -> Result<usize, ParseError> {
        let mut reported = false;
        loop {
            self.eat_trivia();
            match self.peek() {
                Some(token) if token.kind == SyntaxKind::Minus => {
                    if nesting >= MAX_NESTING {
                        return Err(self.error("expression nesting limit exceeded"));
                    }
                    self.builder.start_node(SyntaxKind::UnaryExpr.into_raw());
                    self.bump();
                    let result = self.unary(nesting + 1);
                    self.builder.finish_node();
                    return result.map(|height| height + 1);
                }
                Some(token) if matches!(token.kind, SyntaxKind::Number | SyntaxKind::LeftParen) => {
                    return self.primary(nesting);
                }
                None
                | Some(Token {
                    kind:
                        SyntaxKind::Plus | SyntaxKind::Star | SyntaxKind::Slash | SyntaxKind::RightParen,
                    ..
                }) => {
                    if !reported {
                        let error = self.error("expected an expression");
                        self.errors.push(error);
                    }
                    self.missing_expression();
                    return Ok(0);
                }
                Some(_) => {
                    let error = self.error("expected an expression");
                    self.errors.push(error);
                    self.bump();
                    reported = true;
                }
            }
        }
    }
```

Each loop iteration consumes trivia, then recognizes a real operand,
returns a missing slot at a boundary, or consumes one unexpected token.
`reported` prevents a redundant missing-operand message after this same
attempt has already diagnosed skipped text. It doesn't suppress errors in
a new operand attempt after another operator.

The `None | Some(Token { ... })` pattern groups EOF and the named boundary
tokens into one case. The `..` leaves unrelated token fields out of the
pattern. The Rust Book explains [multiple patterns](https://doc.rust-lang.org/book/ch19-03-pattern-syntax.html#multiple-patterns)
and [destructuring structs](https://doc.rust-lang.org/book/ch19-03-pattern-syntax.html#destructuring-structs).

The minus branch keeps its saved-result/finish-node discipline. Its guard
still rejects a 65th wrapper. Number and group starters still use
`primary`; its fallback is now an internal invariant, since `unary` checks
those starters before calling it. Change just that arm:

```diff title="rlox/crates/syntax/src/cst.rs · primary dispatch invariant"
-            _ => Err(self.error("expected an expression")),
+            _ => unreachable!("unary checks primary starters"),
```

Malformed input takes the recovery branches above; it cannot reach this
private invariant arm. We haven't taught the arithmetic grammar to accept
other Lox operators or values.

The infix loops need no changes. For `* 2`, the first unary call returns a
missing left expression without consuming the star. The factor loop then
consumes `*` and parses `2` as the right operand. Both slots are present
when it wraps the binary node. For `1 +`, the right operand returns a
missing node at EOF and the term loop can finish the sum.

## Let a group consume its own close

For `(1 + )`, the missing right operand leaves `)` untouched. The group
can now consume its own closing token. We also want `(1 @)` to retain the
bad character, report it, and still find the close rather than abandon
the group.

Insert this helper **before `group`** in **`cst.rs`**:

```rust title="rlox/crates/syntax/src/cst.rs · group closer recovery"
    fn close_group(&mut self) {
        loop {
            self.eat_trivia();
            match self.peek() {
                Some(token) if token.kind == SyntaxKind::RightParen => {
                    self.bump();
                    break;
                }
                Some(_) => {
                    let error = self.error("expected ')'");
                    self.errors.push(error);
                    self.bump();
                }
                None => {
                    let error = self.error("expected ')'");
                    self.errors.push(error);
                    break;
                }
            }
        }
    }
```

It consumes a real close and stops, consumes an unexpected token and
continues, or records a missing close at EOF and stops. It never synthesizes
a `RightParen` token. Skipped tokens stay inside the open grouping node.
This is a local scan to the next `)`, not a grammar for the skipped text;
it doesn't recognize nested expressions in that skipped suffix.

## Finish ordinary recovery, stop on resource failure

Replace the public **`parse` function in `cst.rs`** with:

```rust title="rlox/crates/syntax/src/cst.rs · root and error result"
pub fn parse(source: &str) -> Result<Parse, SourceTooLarge> {
    let mut parser = Parser::new(source)?;
    parser.builder.start_node(SyntaxKind::Root.into_raw());
    if let Err(error) = parser.expression(0) {
        parser.errors.push(error);
        while parser.current < parser.tokens.len() {
            parser.bump();
        }
    } else {
        parser.eat_trivia();
        while parser.peek().is_some() {
            let error = parser.error("expected end of input");
            parser.errors.push(error);
            parser.bump();
            parser.eat_trivia();
        }
    }
    parser.builder.finish_node();
    let root = SyntaxNode::new_root(parser.builder.finish());
    Ok(Parse {
        root,
        errors: parser.errors,
    })
}
```

After an ordinary expression result, the root reports any remaining
non-trivia tokens and retains them. A stray `)` at the root has no group
to consume it; it stays there with an error. We still parse one expression,
not a sequence of expression statements.

An `Err` from the expression stops grammar work. That is our resource-limit
exit: record it, retain the suffix without further syntax diagnostics,
then close the root. `parser.errors` moves into the same public result as
its finished tree. The fields own their data; callers can inspect both.

Every recovery path must make progress in one of three ways:

- consume a token;
- return to a caller that owns the current operator or delimiter;
- stop grammar work and retain the remaining suffix.

EOF also returns immediately. Prefix recursion remains bounded by the
existing nesting guard; repeated binary wrappers remain bounded by the
height checks. A zero-width node doesn't itself provide progress, so it
must be followed by a return to a caller that consumes or stops. These
are the expression-level counterpart of the [recovery principles in Crafting Interpreters](https://craftinginterpreters.com/parsing-expressions.html#syntax-errors),
without introducing statement synchronization.

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Token {
    pub kind: SyntaxKind,
    pub range: TextRange,
}

pub fn scan(source: &str) -> Result<Vec<Token>, SourceTooLarge> {
    checked_size(source.len())?;
    let mut tokens = Vec::new();

    for (result, span) in SyntaxKind::lexer(source).spanned() {
        let kind = match result {
            Ok(kind) => kind,
            Err(()) => SyntaxKind::Error,
        };
        let range = checked_range(
            checked_size(span.start).expect("validated source length"),
            checked_size(span.end).expect("validated source length"),
        )
        .expect("Logos spans are ordered");

        tokens.push(Token { kind, range });
    }

    Ok(tokens)
}

pub fn parse(source: &str) -> Result<Parse, SourceTooLarge> {
    let mut parser = Parser::new(source)?;
    parser.builder.start_node(SyntaxKind::Root.into_raw());
    if let Err(error) = parser.expression(0) {
        parser.errors.push(error);
        while parser.current < parser.tokens.len() {
            parser.bump();
        }
    } else {
        parser.eat_trivia();
        while parser.peek().is_some() {
            let error = parser.error("expected end of input");
            parser.errors.push(error);
            parser.bump();
            parser.eat_trivia();
        }
    }

    let root = SyntaxNode::new_root(parser.builder.finish());
    Ok(Parse {

        errors: parser.errors,
    })

    source: &'src str,
    tokens: Vec<Token>,
    current: usize,
    errors: Vec<ParseError>,
    builder: GreenNodeBuilder<'static>,
}

impl<'src> Parser<'src> {
    fn new(source: &'src str) -> Result<Self, SourceTooLarge> {
        Ok(Self {
            source,
            tokens: scan(source)?,
            current: 0,
            errors: Vec::new(),
            builder: GreenNodeBuilder::new(),
        })
    }

    fn peek(&self) -> Option<Token> {
        self.tokens.get(self.current).copied()
    }

    fn peek_non_trivia(&self) -> Option<Token> {
        self.tokens[self.current..]
            .iter()
            .copied()
            .find(|token| !matches!(token.kind, SyntaxKind::Whitespace | SyntaxKind::LineComment))
    }

    fn bump(&mut self) {
        let token = self.tokens[self.current];
        let spelling = slice(self.source, token.range).expect("scanner ranges are valid");
        self.builder.token(token.kind.into_raw(), spelling);
        self.current += 1;
    }

        while let Some(token) = self.peek() {
            if !matches!(token.kind, SyntaxKind::Whitespace | SyntaxKind::LineComment) {
                break;
            }
            self.bump();
        }
    }

                ParseError {
                    message: message.to_owned(),
                    range: checked_range(end, end).expect("ordered EOF range"),
                }
            }

    }

    fn expression(&mut self, nesting: usize) -> Result<usize, ParseError> {
        self.term(nesting)
    }

    fn term(&mut self, nesting: usize) -> Result<usize, ParseError> {
        self.eat_trivia();
        let checkpoint = self.builder.checkpoint();
        let mut height = self.factor(nesting)?;

        while let Some(operator) = self.peek_non_trivia() {
            if !matches!(operator.kind, SyntaxKind::Plus | SyntaxKind::Minus) {
                break;
            }
            self.eat_trivia();
            self.bump();
            let right_height = self.factor(nesting)?;
            let next_height = 1 + height.max(right_height);
            if nesting + next_height > MAX_NESTING {
                return Err(ParseError {
                    message: "expression nesting limit exceeded".to_owned(),
                    range: operator.range,
                });
            }
            self.builder
                .start_node_at(checkpoint, SyntaxKind::BinaryExpr.into_raw());
            self.builder.finish_node();
            height = next_height;
        }

        Ok(height)
    }

    fn factor(&mut self, nesting: usize) -> Result<usize, ParseError> {
        self.eat_trivia();
        let checkpoint = self.builder.checkpoint();
        let mut height = self.unary(nesting)?;

        while let Some(operator) = self.peek_non_trivia() {
            if !matches!(operator.kind, SyntaxKind::Star | SyntaxKind::Slash) {
                break;
            }
            self.eat_trivia();
            self.bump();
            let right_height = self.unary(nesting)?;
            let next_height = 1 + height.max(right_height);
            if nesting + next_height > MAX_NESTING {
                return Err(ParseError {
                    message: "expression nesting limit exceeded".to_owned(),
                    range: operator.range,
                });
            }
            self.builder
                .start_node_at(checkpoint, SyntaxKind::BinaryExpr.into_raw());
            self.builder.finish_node();
            height = next_height;
        }

        Ok(height)
    }

    fn missing_expression(&mut self) {
        self.builder.start_node(SyntaxKind::MissingExpr.into_raw());
        self.builder.finish_node();
    }

    fn unary(&mut self, nesting: usize) -> Result<usize, ParseError> {
        let mut reported = false;
        loop {
            self.eat_trivia();
            match self.peek() {
                Some(token) if token.kind == SyntaxKind::Minus => {
                    if nesting >= MAX_NESTING {
                        return Err(self.error("expression nesting limit exceeded"));
                    }
                    self.builder.start_node(SyntaxKind::UnaryExpr.into_raw());
                    self.bump();
                    let result = self.unary(nesting + 1);
                    self.builder.finish_node();
                    return result.map(|height| height + 1);
                }
                Some(token) if matches!(token.kind, SyntaxKind::Number | SyntaxKind::LeftParen) => {
                    return self.primary(nesting);
                }
                None
                | Some(Token {
                    kind:
                        SyntaxKind::Plus | SyntaxKind::Star | SyntaxKind::Slash | SyntaxKind::RightParen,
                    ..
                }) => {
                    if !reported {
                        let error = self.error("expected an expression");
                        self.errors.push(error);
                    }
                    self.missing_expression();
                    return Ok(0);
                }
                Some(_) => {
                    let error = self.error("expected an expression");
                    self.errors.push(error);
                    self.bump();
                    reported = true;
                }
            }
        }
    }

    fn primary(&mut self, nesting: usize) -> Result<usize, ParseError> {
        match self.peek() {
            Some(token) if token.kind == SyntaxKind::Number => {
                self.builder.start_node(SyntaxKind::NumberExpr.into_raw());
                self.bump();
                self.builder.finish_node();
                Ok(0)
            }
            Some(token) if token.kind == SyntaxKind::LeftParen => self.group(nesting),
            _ => unreachable!("unary checks primary starters"),
        }
    }

    fn close_group(&mut self) {
        loop {
            self.eat_trivia();
            match self.peek() {
                Some(token) if token.kind == SyntaxKind::RightParen => {
                    self.bump();
                    break;
                }
                Some(_) => {
                    let error = self.error("expected ')'");
                    self.errors.push(error);
                    self.bump();
                }
                None => {
                    let error = self.error("expected ')'");
                    self.errors.push(error);
                    break;
                }
            }
        }
    }

    fn group(&mut self, nesting: usize) -> Result<usize, ParseError> {
        if nesting >= MAX_NESTING {
            return Err(self.error("expression nesting limit exceeded"));
        }
        self.builder.start_node(SyntaxKind::GroupingExpr.into_raw());
        self.bump();
        let result = match self.expression(nesting + 1) {
            Err(error) => Err(error),
            Ok(inner_height) => {
                self.close_group();
                Ok(inner_height + 1)
            }
        };
        self.builder.finish_node();
        result
    }
}

    fn shape(node: &SyntaxNode) -> String {
        match node.kind() {
            SyntaxKind::NumberExpr => node.to_string(),
            SyntaxKind::GroupingExpr => {
                format!("(group {})", shape(&node.first_child().expect("operand")))
            }
            SyntaxKind::UnaryExpr => {
                format!("(- {})", shape(&node.first_child().expect("operand")))
            }
            SyntaxKind::BinaryExpr => {
                let mut operands = node.children();
                let left = operands.next().expect("left operand");
                let right = operands.next().expect("right operand");
                let operator = node
                    .children_with_tokens()
                    .filter_map(|element| element.into_token())
                    .find(|token| {
                        matches!(
                            token.kind(),
                            SyntaxKind::Plus
                                | SyntaxKind::Minus
                                | SyntaxKind::Star
                                | SyntaxKind::Slash
                        )
                    })
                    .expect("operator");
                format!("({} {} {})", operator.text(), shape(&left), shape(&right))
            }
            kind => panic!("unexpected complete expression kind: {kind:?}"),
        }
    }
